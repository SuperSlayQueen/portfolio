# Мурина Софья — Portfolio

Одностраничное портфолио графического и UX/UI-дизайнера.

**Сайт:** https://superslayqueen.github.io/portfolio/

## Структура

- `index.html` — главная
- `works.html` — каталог работ
- `about.html` — обо мне
- `projects/` — кейсы с экранами
- `assets/projects/` — оптимизированные изображения

## Как обновить сайт на GitHub Pages

1. Измени файлы локально в этой папке.
2. В терминале из папки проекта:

```bash
git add .
git commit -m "Описание изменений"
git push
```

Через 1–2 минуты обновления появятся на https://superslayqueen.github.io/portfolio/
